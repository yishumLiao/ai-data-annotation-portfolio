# 质检核对清单（交付前逐项打勾）

版本：v1.0（2026-11-18）　用法：标注员自检 100% 执行；QC 抽检按此单复核并记录命中项。

## A. 格式与结构（逐条数据）

- [ ] JSON 可解析，无尾逗号、无未转义字符
- [ ] `id` 唯一且符合前缀规则
- [ ] 枚举字段取值合法（task_type / domain / difficulty / verdict）
- [ ] messages 角色交替、以 assistant 结尾
- [ ] 字段完整，无空值冒充（缺项必须显式标注）

## B. 内容质量

- [ ] 事实类内容已按官方口径核对（名称、数字、政策为现行版本）
- [ ] 无编造数据：所有具体数字、引用、规则有出处或已声明局限
- [ ] 显式要求逐条满足（字数、格式、要点数、角色）
- [ ] 多轮对话：指代一致、前轮确认信息未被篡改
- [ ] 安全：有害请求无方法泄露；无害请求未被误拒
- [ ] 医疗/法律/金融内容只含通用信息，且有就医/咨询信号

## C. 一致性与偏差

- [ ] 判定与规范锚定一致（同一档行为同一分）
- [ ] 偏好标注已做 AB 交换复评（swap_recheck = true）
- [ ] 无连续同侧（同一提交批内偏好单侧率 ≤ 70%）

## D. 合规与留痕

- [ ] 个人信息已脱敏（手机号、证件号、住址）
- [ ] `quality_check` / `evidence` 字段如实填写，与内容对得上
- [ ] 不合格项已记录 badcase 编号，返修项闭环
